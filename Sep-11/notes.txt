

Database :  A database is set of interrelated files, stored with min. redundancy to serve many users work concurrently. 

DBMS (Database Management System) 

	The software that which allows you to perform transactions on data like 

	(i) Adding New Data

	(ii) Modifying already existing data

	(iii) Removing unwanted data 

Objectives : 

	(i) Provides an efficient and convinient env, that which allows you to store data in and retrieve data 

	(ii) Granting access on data to the users based on their credentials. 

Data Model : It is description of organization of database, and also describes the relationships among the data. 

There are 2 types of data models known as

(i) Object based data model

	Focuses on attributes and relationships

(ii) Record Based 

	Represent data in practical way

Relational model says data to be represented in form of tables. 

A table stores data in terms of rows and columns. 

No.of rows are called cardinality.

No.of attributes are called degree.

Relationals system stores data in terms of keys. 

There are various types of keys known as 

Employee(Empno,Name,Gender,Deptno,Salary,AadharNo,SalaryDate)

(i) Candidate Key : Any key that which uniquely identifies rows of a table known as candidate key. 

(Empno, AadharNo) are candidate keys. 

(ii) Primary Key : One of the candidate key needs to be chosen as primary key based on priority. (Empno) 

	-> Primary key cannot be null

	-> Primary Key cannot be duplicated

(iii) Alternate Key : Any key that which is candidate key but not primary key known as alternate key. 

(iv) Composite Key : Any key that which uniquely identifies rows of a table made up of more than one attribute known as composite key. (Empno + SalDate) 

(v) Foreign Key : Primary key in the parent table will be foreign key in the child table.
